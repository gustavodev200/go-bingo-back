# Go Bingo Front — M2 (PWA e Mobile) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tornar o Go Bingo instalável (manifest + ícones + service worker), com fallback offline, aviso de rede, Wake Lock durante a partida, convite de instalação (Android e iOS) e acabamento mobile (safe-area, sem zoom acidental).

**Architecture:** Tudo no repo `go-bingo-front`; nenhuma mudança no back. Manifest via `app/manifest.ts`; ícones PNG gerados em build por um route handler com `ImageResponse`; service worker via Serwist com **`@serwist/turbopack`** (Next 16 usa Turbopack por padrão) servido por route handler. O SW faz precache só da página `/~offline` e cache-first só de assets estáticos **do próprio origin** — nunca de respostas da API nem de HTML autenticado. Regras de cache e de plataforma ficam em funções puras testáveis em `src/lib/pwa/`; hooks (`useOnlineStatus`, `useWakeLock`, `useInstallPrompt`) isolam as APIs do navegador.

**Tech Stack:** Next.js 16 (App Router, `proxy.ts`), React 19, TypeScript, Tailwind 4, `@serwist/turbopack` + `serwist`, Vitest + Testing Library.

**Spec:** [docs/PRD.md](../../PRD.md) — E6 (US-6.1, US-6.2, US-6.3), marco M2 (§6.1), riscos de OAuth em PWA no iOS · Roadmap: [2026-10-05-roadmap.md](2026-10-05-roadmap.md) · Plano anterior: [2026-10-05-front-m0-m1-core.md](2026-10-05-front-m0-m1-core.md)

## Global Constraints

- Nome do produto: **"Go Bingo"** (resolve Q7 do PRD; já é o nome no `metadata`). Cor do tema `#4c1d95` (a mesma do `viewport.themeColor`).
- Manifest (US-6.1): nome, ícones **192 e 512 + maskable**, `display: "standalone"`, cores do tema, `orientation: "any"`.
- O service worker **nunca** cacheia: respostas de outro origin (a API Nest e o Supabase estão em outros origins), HTML/RSC de páginas (dependem de cookie de sessão), nem `/serwist/sw.js`. Só assets estáticos do mesmo origin.
- Sem rede, navegação cai em `/~offline` com o texto **"Você está offline"** (US-6.2). Não existe modo offline de partida.
- A página `/~offline`, `/serwist/*`, `/pwa-icons/*` e o manifest devem ser acessíveis **sem sessão** (o `proxy.ts` não pode redirecioná-los para `/login`).
- Safe-area: respeitar `env(safe-area-inset-*)`; usar `dvh`; `touch-action: manipulation` global (sem zoom por double-tap) — sem desabilitar pinch-zoom (acessibilidade: não usar `maximum-scale`).
- Wake Lock só durante a partida (`status === 'IN_GAME'`), quando suportado; falha/negação nunca interrompe o jogo.
- Textos de interface em pt-BR.
- `src/contracts/` é gerado — não editar.
- Constituição, Princípio VIII: cobertura ≥ 80% (statements/branches/functions/lines). Este plano adiciona à exclusão de cobertura **somente** arquivos de wiring sem lógica: `src/app/sw.ts`, `src/app/serwist/**`, `src/app/pwa-icons/**` (Task 2 e Task 1). Toda lógica de decisão fica em `src/lib/pwa/` e `src/features/pwa/` (cobertos).
- Comandos assumem Git Bash no Windows, a partir de `E:/projetos/go-bingo/go-bingo-front`. Trabalhar na branch `feat/front-m2-pwa` criada a partir de `main`.
- Trailer de commit: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **SW cacheando resposta autenticada/da API** (ex.: `GET {API}/rooms`, `GET {API}/ranking`, HTML de `/`) → nunca cacheia; só `/_next/static/**` e `/pwa-icons/**` do mesmo origin. Teste em Task 2 (`isCacheableAsset`).
2. **Offline + sem sessão válida** → navegação mostra `/~offline`, não `/login`; `/~offline`, `/serwist/sw.js`, `/manifest.webmanifest` e `/pwa-icons/*` passam pelo `proxy.ts` sem redirecionar. Teste em Task 1 (matcher).
3. **Wake Lock indisponível, negado ou perdido ao trocar de aba** → o jogo segue; ao voltar à aba, o lock é readquirido; ao sair da partida, é liberado. Testes em Task 4.
4. **Convite de instalação em lugar errado**: já instalado (standalone), navegador embutido do Instagram/Facebook, iOS (não existe `beforeinstallprompt`), usuário já dispensou, `localStorage` bloqueado → o card certo (ou nenhum) e nenhuma exceção. Testes em Task 5.
5. **Usuário offline no meio da partida** → banner "Você está offline" aparece e some ao voltar a rede; socket já tem o banner de "Reconectando…". Testes em Task 3.

```ts
  { file: 'icon-512.png', size: 512, maskable: false },
```

```tsx
import { ImageResponse } from 'next/og';
import { PWA_ICONS, findIcon } from '@/lib/pwa/icons';

export const dynamic = 'force-static';

export function generateStaticParams() {
  return PWA_ICONS.map(({ file }) => ({ file }));
}

export async function GET(_request: Request, { params }: { params: Promise<{ file: string }> }) {
  const icon = findIcon((await params).file);
  if (!icon) return new Response('Not found', { status: 404 });
  const fontSize = Math.round(icon.size * (icon.maskable ? 0.5 : 0.64));
  return new ImageResponse(
    (
      <div
        style={{
          width: '100%',
          height: '100%',
          display: 'flex',
          alignItems: 'center',
          justifyContent: 'center',
          background: '#4c1d95',
          color: '#ffffff',
          fontSize,
          fontWeight: 900,
        }}
      >
        B
      </div>
    ),
    { width: icon.size, height: icon.size },
  );
}
```

`src/lib/pwa/cache-rules.ts`:

```ts
const CACHEABLE_PREFIXES = ['/_next/static/', '/pwa-icons/'];

/** Só assets estáticos do próprio origin. API, Supabase, HTML e RSC dependem de sessão/estado e nunca entram no cache. */
export function isCacheableAsset(url: URL, selfOrigin: string): boolean {
  return url.origin === selfOrigin && CACHEABLE_PREFIXES.some((prefix) => url.pathname.startsWith(prefix));
}
```

`src/app/sw.ts` (import **relativo**: o esbuild do Serwist pode não resolver o alias `@/`):

```ts
/// <reference lib="esnext" />
/// <reference lib="webworker" />
import { CacheFirst, ExpirationPlugin, NetworkOnly, Serwist } from 'serwist';
import type { PrecacheEntry, SerwistGlobalConfig } from 'serwist';
import { isCacheableAsset } from '../lib/pwa/cache-rules';

declare global {
  interface WorkerGlobalScope extends SerwistGlobalConfig {
    __SW_MANIFEST: (PrecacheEntry | string)[] | undefined;
  }
}

declare const self: ServiceWorkerGlobalScope;

const serwist = new Serwist({
  precacheEntries: self.__SW_MANIFEST,
  skipWaiting: true,
  clientsClaim: true,
  navigationPreload: true,
  runtimeCaching: [
    {
      matcher: ({ url }) => isCacheableAsset(url, self.location.origin),
      handler: new CacheFirst({
        cacheName: 'static-assets',
        plugins: [new ExpirationPlugin({ maxEntries: 150, maxAgeSeconds: 30 * 24 * 60 * 60 })],
      }),
    },
    // Navegação vai sempre à rede; se falhar, o fallback abaixo serve /~offline.
    { matcher: ({ request }) => request.mode === 'navigate', handler: new NetworkOnly() },
  ],
  fallbacks: {
    entries: [{ url: '/~offline', matcher: ({ request }) => request.destination === 'document' }],
  },
});

serwist.addEventListeners();
```

```ts
import { useEffect } from 'react';

/** Mantém a tela acesa enquanto `active`. Sem suporte, negação ou perda do lock nunca afetam o jogo. */
export function useWakeLock(active: boolean): void {
  useEffect(() => {
    if (!active || !('wakeLock' in navigator)) return;
    let sentinel: WakeLockSentinel | null = null;
    let cancelled = false;

    const acquire = async () => {
      try {
        const next = await navigator.wakeLock.request('screen');
        if (cancelled) {
          void next.release().catch(() => undefined);
          return;
        }
        sentinel = next;
      } catch {
        // Negado (bateria baixa, aba oculta): segue sem manter a tela acesa.
      }
    };
    const onVisibility = () => {
      if (document.visibilityState === 'visible' && (!sentinel || sentinel.released)) void acquire();
    };

    void acquire();
    document.addEventListener('visibilitychange', onVisibility);
    return () => {
      cancelled = true;
      document.removeEventListener('visibilitychange', onVisibility);
      void sentinel?.release().catch(() => undefined);
    };
  }, [active]);
}
```

```ts
'use client';

import { useCallback, useEffect, useState } from 'react';
import { isInAppBrowser } from '@/lib/in-app-browser';
import { isIos, isStandalone } from '@/lib/pwa/platform';

export type InstallMode = 'hidden' | 'prompt' | 'ios';

type BeforeInstallPromptEvent = Event & {
  prompt: () => Promise<void>;
  userChoice: Promise<{ outcome: 'accepted' | 'dismissed' }>;
};

const DISMISS_KEY = 'go-bingo:install-dismissed';

function wasDismissed(): boolean {
  try {
    return localStorage.getItem(DISMISS_KEY) === '1';
  } catch {
    return false;
  }
}

function rememberDismissal() {
  try {
    localStorage.setItem(DISMISS_KEY, '1');
  } catch {
    // Armazenamento bloqueado: some só nesta sessão.
  }
}

export function useInstallPrompt() {
  const [mode, setMode] = useState<InstallMode>('hidden');
  const [deferred, setDeferred] = useState<BeforeInstallPromptEvent | null>(null);

  useEffect(() => {
    if (isStandalone() || isInAppBrowser(navigator.userAgent) || wasDismissed()) return;
    if (isIos(navigator.userAgent, navigator.maxTouchPoints)) setMode('ios');

    const onBeforeInstall = (event: Event) => {
      event.preventDefault();
      setDeferred(event as BeforeInstallPromptEvent);
      setMode('prompt');
    };
    const onInstalled = () => {
      setDeferred(null);
      setMode('hidden');
    };
    window.addEventListener('beforeinstallprompt', onBeforeInstall);
    window.addEventListener('appinstalled', onInstalled);
    return () => {
      window.removeEventListener('beforeinstallprompt', onBeforeInstall);
      window.removeEventListener('appinstalled', onInstalled);
    };
  }, []);

  const install = useCallback(async () => {
    if (!deferred) return;
    await deferred.prompt();
    await deferred.userChoice;
    setDeferred(null);
    setMode('hidden');
  }, [deferred]);

  const dismiss = useCallback(() => {
    rememberDismissal();
    setMode('hidden');
  }, []);

  return { mode, install, dismiss };
}
```
